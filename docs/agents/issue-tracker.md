# Project coordination

Use [GitHub Issues](https://github.com/larsmartens/signal-decision-lab/issues) to track work and [main](https://github.com/larsmartens/signal-decision-lab/tree/main) as the shared baseline. Pull requests review changes to main. Keep one tracker for the project.

The [specification](../SPEC.md) defines required behavior. The [plan](../PLAN.md) sets milestones, and the [evaluation protocol](../EVALUATION.md) defines the evidence needed to assess them. Link an issue to the relevant requirement and state how completion will be checked. Record changed assumptions and unresolved findings in the issue.

Use the connected GitHub tools or an authenticated `gh` CLI. Never describe a planned check as completed or carry historical Jeff results forward as Jev evidence.
